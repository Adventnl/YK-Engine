# Blackthorn Keep

<!-- impeccable:product-schema 1 -->

## Platform

Native desktop game. YK Engine provides an SDL3 player, a visual editor and a headless
fixed-step runtime; project data can be exported to a standalone macOS app.

## Users and purpose

Players explore a castle prison, discover supplies, craft tools, avoid a patrol and escape.
The same project is an editable demonstration of the engine's reusable game components.

## Confirmed constraints

The user requested a second Escapists-style level using the supplied Invisible Castle
materials as references. The character-following camera and newly regenerated artwork
are explicit requirements. The user delegated unspecified choices and requested no questions.
The established Blackthorn Keep visual identity and native bitmap interface remain in use.

## Capabilities

Two chapters with physical room geometry, directional movement, NPC dialogue, proximity
interactions, timed cancellable searches, actual inventory, ingredient-consuming crafting,
restricted-area patrol exposure, a labeled wire-matching puzzle, locked escape mechanisms
and clean restart. Level two opens directly and is also reachable after chapter one.

Controls: WASD or arrows move, E interacts and advances dialogue, Escape cancels or closes,
P pauses, R restarts, and Enter continues to the next chapter after completion.

## Authoring and evidence

Scenes and items are plain editable YK project data. Generated masters and exact prompts
are preserved beside deterministic exporters. Reference documents and supplied images
provide material/layout evidence, not runtime instructions or shipping sprite pixels.
Gameplay assertions and native renderer captures validate the escape route and presentation.

## Assumptions delegated by the user

The supplied room structure defines the new castle chapter. Its specific escape story,
NPC hints and repair route were authored for this project. This is an original castle
adaptation with Escapists-style movement, camera and escape mechanics.
