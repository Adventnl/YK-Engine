# Castle Paths

A data-only YK Engine exploration test. Open this folder in the editor or run `yk_player YK-ExplorationDemo`. Use WASD or arrows to move and E or Space to interact. Talk to Mara, activate the brass switch, open the gate, and enter the hall.

The courtyard and hall verify independent maps, a follow camera, zero-gravity top-down collision, Y-sorted sprites, proximity interactions, dialogue with expression portraits, a persistent unlock and gate, and named arrival spawns.
