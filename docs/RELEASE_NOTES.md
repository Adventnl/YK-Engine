Download the installer for your computer below. The engine, editor, player, sample projects, and required SDL/Box2D libraries are included. You do not need CMake, Ninja, Visual Studio, or a compiler.

Version 0.3.1 adds the **Fireboy and Watergirl** playable sample. Open it from the editor welcome screen, or run it with the bundled player. It includes its level, character animations, art, sound, and two-player controls.

- **Windows x64:** Download the `windows-x64.exe` file and follow its setup wizard. It adds YK Engine to the Start menu and provides an uninstaller.
- **Mac with Apple silicon:** Download the `.pkg` for the macOS Installer wizard, or the `.dmg` to drag YK Engine into Applications.

These builds are not code signed with a trusted developer certificate. Windows SmartScreen may ask you to choose **More info > Run anyway**. On macOS, use **Control-click > Open** on the first launch if Gatekeeper blocks the app. Only download the installers from this repository's Releases page.
